# Nobelprisanalyse

Dag 79 af Udemys *100 Days of Code*: analysér tidligere vindere af Nobelprisen med Pandas, Plotly, Matplotlib og Seaborn. Denne wiki forklarer hvad hvert trin i lektionen lærer. Hvert trin har et skærmbillede af sin lektion.

| Side | Hvad du får |
| --- | --- |
| [Kom i gang](Getting-Started-da) | En `.venv`, installationen, og hvordan projektet køres og testes på Windows og Linux |
| [Trin 1: Dagens mål](Step-1-Goals-da) | Hvad skal vi bygge, og hvilke værktøjer skal vi bruge? |
| [Trin 2: Udforsk og rens datasættet](Step-2-Explore-and-Clean-da) | Hvordan ser data ud, og hvad mangler? |
| [Trin 3: Søjle- og donutdiagrammer med plotly](Step-3-Bar-and-Donut-Charts-da) | Hvilke kategorier uddeler flest priser, og hvor mange gik til kvinder? |
| [Trin 4: Tendenser over tid med Matplotlib](Step-4-Trends-over-Time-da) | Uddeles der flere priser nu end i begyndelsen? |
| [Trin 5: Et choropleth-kort og de bedste lande](Step-5-Choropleth-Map-da) | Hvilke lande vinder flest priser? |
| [Trin 6: Sunburst-diagrammer over forskningssteder](Step-6-Sunburst-Charts-da) | Hvilke institutioner og byer er hotspots for opdagelser? |
| [Trin 7: Modtagernes alder](Step-7-Laureate-Age-da) | Hvor gamle er modtagere, når de vinder, og har det ændret sig? |
| [Trin 8: Læringspunkter og opsummering](Summary-da) | Alt hvad lektionen lærte, på én liste |

Opgavens spørgsmål: datas form og kvalitet, kategorier og kvindelige modtagere, priser over tid, de bedste lande, organisationer og byer samt modtagernes alder.
