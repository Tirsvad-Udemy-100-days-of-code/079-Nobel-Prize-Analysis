## Purpose

Decides whether S02 and S03 can understand, run and learn from the repository without help: a working Jupyter notebook, a README, one screenshot per lecture step and a wiki in English, Danish and Bahasa Malaysia.

## Deliverable

`notebooks/Nobel_Prize_Analysis.ipynb` that runs top to bottom, eight lecture screenshots in `docs/images/`, a README built from the framework template, and a flat `docs/wiki/` with the same page set in English, Danish (`-da`) and Bahasa Malaysia (`-ms`), including Getting Started guides for Linux and Windows.
